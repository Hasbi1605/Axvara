- Lease dan throttle sukses tetap 45 detik; kegagalan memperpendek klaim miliknya menjadi backoff 10 detik setelah kegagalan. ## Kredensial dan saklar Pages — 18 November 2026

- Klien server di `src/lib/mirai/client.ts`: base URL bawaan `https://api.miraiapi.com/api/reseller/v1`, header `Authorization: Bearer <kunci>`. HTTPS saja, redirect tidak diikuti. URL bawaan adalah konstanta publik kode, bukan salinan nilai berkas lokal.
- Sumber lokal: `axvara/.mirai-credentials` (izin `chmod 600`; pola `.gitignore` `.mirai-credentials*` di checkout utama). Hanya nama kunci: `MIRAI_API_KEY`, `MIRAI_BASE_URL`. Jangan baca untuk QA dokumentasi, cetak, log, stage, atau commit isinya.
- Empat env Pages, semuanya `secret_text`: `MIRAI_API_KEY`, `MIRAI_BASE_URL`, `MIRAI_ENABLED`, `MIRAI_SYNC_ENABLED`. **Kedua** flag wajib `true` untuk sync dan dispatch; kosong/bukan `true` = OFF. Key dan URL valid juga wajib. Pembacaan saldo administratif/monitoring dapat berjalan bila terkonfigurasi tanpa membuka pembelian. Ikuti [aturan env Pages](../ARCHITECTURE.md#162-env-pages-wajib-secret_text-bukan-plain_text).

## Identitas, katalog, dan harga — 18 November 2026

- `products.mirai_family`, `product_variants.mirai_package_code`, SKU `MR-<package_code>` (pertahankan huruf/underscore kode). `src/lib/mirai/families.ts` mengelompokkan 15 paket snapshot ke `gpt`, `claude`, `full`, `tau`; grup asing fallback `package:<code>` dengan slug berhash. Label berdasarkan kuota dan durasi. `source` dan mode internal `manual` bukan penanda fulfillment stok sendiri.
- `lite:mirai_catalog` tiap menit: `GET /packages`, throttle/lease 45 detik, hormati `Retry-After` saat 429. Paket hilang tetap dimirror sebagai tidak aktif, stok nol; paket unlimited aktif diproyeksikan `stock=-1`. Penanda sukses hanya setelah mirror + proyeksi. Induk/varian baru OFF, Arsip tidak dibuka lagi oleh sync. Nama, deskripsi, label, gambar, dan kategori milik admin sesudah insert. Kurasi ID/EN dan gambar R2 ditetapkan saat pertama dibuat **setelah paket kurasi T6b terintegrasi**, tanpa menimpa copy yang sudah tersimpan.
- Modal `reseller_price_vnd ÷ 26.000` → USDT (maks. enam desimal), harga = modal USDT × kurs snapshot AXVARA × (1 + markup/100), dibulatkan ke atas ke kelipatan Rp100. Tanpa kurs valid gagal tertutup. Default markup 35%; `mirai_cost_usdt`, `mirai_fx_idr_per_usdt`, `mirai_markup_percent`, `mirai_admin_price_idr` (NULL = rumus). Sesuai owner, **USDT saja** untuk modal/saldo Mirai di admin dan notifikasi saldo; harga jual AXVARA tetap Rupiah. VND hanya internal, termasuk verifikasi saldo sebelum beli.

## Pembelian, pemulihan, dan pengiriman — 18 November 2026

- Hanya order apps web/Telegram lunas/paid dengan snapshot `mirai_eligibility` dari server; bukan order lama tanpa snapshot, payment test, atau order dengan pembelian supplier dimatikan. Satu link per order/baris. `external_order_id` dan `Idempotency-Key` stabil `<order_code>-<item_index>`. Tidak memakai supplier cadangan atau membeli lagi untuk memperbaiki kegagalan notifikasi.
- Preflight pertama mengecek mapping aktif, kepemilikan fulfillment, paket dan min/max jumlah, stok harian bila terbatas, serta biaya live dibanding snapshot USDT. Kenaikan harga → `needs_admin` (`price_increased`) sebelum cek saldo/POST; saldo tidak cukup atau gagal dibaca juga ditahan. Lease + compare-and-set memagari order/snapshot/fulfillment dan menulis sent marker + penghitung sebelum POST. Receipt mentah dienkripsi sebelum interpretasi; respons 409 dipetakan ke kode internal (`blocked_balance`, `idempotency_mismatch`, `bad_package`, atau `http_409`).
- Maksimum tiga POST. Saat percobaan sebelumnya ambigu, dahulukan `GET /orders/{external_order_id}`: 200 diproses tanpa POST; 404 sebelum batas percobaan boleh replay body/key yang sama, bukan buat ID baru; 429/5xx ditunda dengan backoff dan `Retry-After`. Sesudah POST ambigu ketiga, tetap GET; 404 sesudah batas → `needs_admin` (`attempts_exhausted`). Retry admin hanya alasan yang diizinkan sebelum POST pertama, tanpa sent marker/kode supplier.
- Hanya `fulfilled` dengan identitas cocok dan **seluruh** kode redeem yang valid (jumlah tepat sesuai pembelian) → `completed`. Jadikan satu baris per kode; field tunggal hanya boleh untuk kuantitas satu jika array absen. Status selain `fulfilled`, kode kurang/lebih/kosong, atau identitas salah → `needs_admin`, tanpa kirim parsial. Pembeli menerima kode untuk diaktifkan sendiri dengan panduan paket (kurasi T6b); AXVARA tidak membuat kunci `sk-` pembeli ataupun melakukan redeem di server.

## Operasi admin dan kurasi — 18 November 2026

- **Supplier → Mirai** (`/admin?section=mirai`): Ringkas (saldo USDT/status), Antrean (100 link terbaru, Retry aman, reveal receipt privat/diaudit dengan field VND dan error mentah dibuang), Markup (override/aktivasi varian), Alat (sinkron paksa). Produk mengelola induk/copy; laporan punya bucket `mirai`; grup produk bukan failover transaksi. Detail schema/API: [ARCHITECTURE §16.59](../ARCHITECTURE.md#1659-storebat-dan-mirai--19-november-2026-implementasi-lokal).
- Cron order mengecek saldo maksimum 1×/30 menit jika terkonfigurasi dan ada budget. Ambang default **5 USDT** (`MIRAI_BALANCE_ALERT_USDT` opsional, di luar delapan env rollout); Telegram admin dibatasi 6 jam atau bila saldo turun ≥ 1 USDT. Gagal baca bukan saldo nol. Watchdog cleanup memantau `mirai_catalog_success_at` selama sync aktif: basi 15 menit, tenggang awal 1 jam; Ringkasan Harian menyertakan kesehatan/saldo dan order macet.
- Tidak ada SKU Mirai tertentu yang diblokir oleh review copy; **seluruh paket tetap OFF** sesuai keputusan rollout. Sebelum kurasi jual, cek tumpang tindih family `claude` dan `gpt` dengan paket kode Mirai yang dijual ulang StoreBat, serta kesiapan saldo; overlap bukan alasan memilih supplier lain untuk order yang sudah masuk.
